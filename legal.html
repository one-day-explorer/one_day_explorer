Privacy Policy

Last updated: 26 October 2026

This Privacy Policy explains how One Day Explorer handles personal data when you visit this website. One Day Explorer is a personal, non-commercial travel archive featuring travel stories, destination pages and an interactive world map.

2. Website Hosting

This website is hosted by using GitHub Pages, a static website hosting service provided by GitHub. When you access the website, technical information required to deliver and protect the service may be processed, including your IP address, request date and time, browser and device information, and requested resources.

GitHub states that IP addresses of visitors to GitHub Pages sites are logged and stored for security purposes. Further information is available in the GitHub Pages documentation and the GitHub Privacy Statement .

3. Interactive World Map

The interactive world map uses Leaflet, a JavaScript mapping library. Map tiles are requested from Stadia Maps. Country boundary data is loaded from a public GeoJSON file hosted on GitHub.

When the map loads or you interact with it, your browser connects to the relevant external servers. These providers may receive technical connection data, including your IP address and requested resources. Their own privacy terms apply to their processing of that information.

  • Stadia Maps Privacy Policy
  • OpenMapTiles Project Information
  • OpenMapTiles Privacy Policy
  • OpenStreetMap Copyright Information
  • Country Boundary Data on GitHub
  • GitHub Privacy Statement

Where applicable, processing by the website controller is based on the legitimate interest in operating a secure and functional website under Article 6(1)(f) GDPR, provided that this interest is not overridden by the rights and freedoms of the person concerned.

External providers process data under their own responsibilities and legal bases as described in their respective privacy notices.
